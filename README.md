# mini-leveldb

- 基于 LSM-Tree 的单机 KV 存储引擎，LevelDB 的简化实现（C++17，目标 ~3000 行）。
- 参考实现：[google/leveldb](https://github.com/google/leveldb)

## 整体架构

```
                          ┌─────────────────────────────┐
       写入               │                             │
Put/Delete ────► WAL 日志 │   顺序追加，崩溃后可回放      │
       │                  │                             │
       └──► MemTable ─────┤   内存中的有序结构            │
                │         │                             │
                │ 写满    │                             │
                ▼         │                             │
            SSTable ──────┤   磁盘上的有序文件            │
                │         │                             │
                │ 层数过多 │                             │
                ▼         └─────────────────────────────┘
            Compaction        后台归并，去重与回收空间
```

```
       读取
Get(key) ──► MemTable（最新）──► SSTable（旧→新逐层）──► 首个命中即返回
```

设计上的两个核心取舍：

- **写快**：随机写全部转为内存操作 + 顺序日志追加，永不就地更新磁盘
- **读稳**：数据在磁盘上始终有序存放，配合索引逐层定位，删除只做标记不做物理清理

崩溃一致性：任何一笔写都先落日志再进内存。进程崩溃后，重启时回放日志即可恢复全部已确认的写入；日志残尾（写了一半的记录）能被校验和识别并安全丢弃。
